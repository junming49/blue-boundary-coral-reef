# 七作品国奖深化版

## 打开方式

打开 index.html 进入七项目目录。每个作品有单独页面，可放在同一个静态网站根目录发布：

- coral.html：蓝色边界：珊瑚修复站
- sync.html：同频舱：多模态无障碍空间导航
- star.html：星问：带证据链的天文导览伙伴
- beidou.html：北斗·归途：一束信号，走出风暴
- movable.html：活字的一夜：字模学徒的印刷工坊
- sound.html：听见校园：隐私优先的声景地图
- quiet.html：一平米静音站：校园微型安静角

静态站点发布目录设为本目录即可。麦克风体验须在 HTTPS 或本机安全上下文中运行；其他交互可直接离线打开。

## 申报简介

- 申报简介_七项目.md：可编辑文本，含赛道建议、简介、现有原型、申报前待完成事项、AI 工具和素材说明初稿。
- 2026全国大学生数字媒体科技作品七项目申报简介初稿.docx：可编辑 Word 文档。

## 原型范围

当前网页为七个可操作的学生创作底稿，不代表真实调研、用户测试、专业审核或实施效果。页面中的虚构情境、规则模型和概念尺度都已标明。比赛指南要求学生团队独立完成核心创作与系统开发；正式申报需由团队完成实质性重制和扩展，保存真实分工、过程、测试、素材授权和 AI 使用记录。
