# 六个差异化互动原型

这六个页面各自是一件独立作品，不再共用同一模板。每页对应一个竞赛方向，并采用不同的视觉语言、核心交互与成果输出。

- 冰芯来信：极地科研决策推演，验证资源取舍和多结局反馈。
- 月背电台：跨媒介线索推理，把遥测、日志、音频和地图串成可复核的证据链。
- 同频舱：无障碍空间导航，支持键盘、触控和浏览器语音能力，并提供对比度、字号与动效设置。
- 声纹织村：口述史视觉共创工作台，支持参数生成、人工修订留痕和 PNG 导出。当前使用本地参数化绘图，不伪称接入在线生成模型。
- 星问：证据优先的天文问答，以本地知识条目回答、展示来源，并对未覆盖问题拒答。
- 镜间：AIGC 短片逐镜一致性审校，支持本地图片预览、人工标签复核与 CSV 报告导出。

## 参赛深化建议

原型演示了交互闭环与作品方向。正式参赛仍需补充真实用户测试、原创素材与授权材料、团队分工、技术架构说明及量化评估数据；涉及 AI 的部分应完整披露模型、版本、提示词、人工修改过程和合规情况。


## 本轮评审导向深化

本轮围绕原创性、技术实现、完成度与可验证性、应用传播和现场演示进行了分作品深化。新增功能用于呈现作品的设计逻辑和过程证据；它们不是国奖结果保证，也不替代真实用户测试、原创成果证明、素材授权和团队贡献材料。

- 珊瑚修复站：增加决策过程与当前生态指标的本地 JSON 导出、珊瑚白化和修复参考资料；页面明确演示数值是规则化教学情境，不是生态预测。
- 冰芯来信：增加每局资源与选择结果记录导出；明确科研站和资源数值为虚构演示，不提供真实极地安全建议。
- 月背电台：增加线索顺序、推理依据和自评置信度导出；标明故事、日志和浏览器合成音效均为虚构演示。
- 同频舱：增加不含身份信息的本地交互日志、无障碍自检入口和隐私说明；真实用户测试结果仍需团队采集。
- 声纹织村：增加工具、提示词、学生原创贡献和素材权利自查的溯源卡；目前是参数化 Canvas 绘图，未接入生成式模型。
- 星问：增加 5 条知识覆盖/拒答边界自检，并保留 NASA 原始来源链接；自检只验证路由边界，不宣称独立科学评测。
- 镜间：增加本地相邻镜头平均 RGB 颜色差异提示、人工复核记录导出和 AI 工作流披露；不识别人物、服装或道具语义。

## 正式参赛前的真实证据清单

1. 由目标用户完成任务测试，保留样本、方法、原始记录与改版前后差异；不要把页面自检当成用户研究。
2. 建立团队成员与代码、交互、内容、素材工作的对应关系，并保留版本记录、草图和演示过程。
3. 逐条核实数据和素材来源、许可、肖像/口述授权；对真实人物故事做好知情同意与匿名化。
4. 若使用生成式工具，逐项披露工具/模型/版本、提示词、生成内容、人工筛选和二次创作，以及合规情况。
5. 准备现场演示脚本、失败边界说明和可复现的安装/访问说明。


## 本轮深化模块

- 珊瑚修复站：一年期、含扰动与不确定带的教学轨迹推演。
- 冰芯来信：可调人员安全阈值的 27 路径敏感性与多目标比较。
- 月背电台：作者公开关联权重、体验者调整可信度的证据敏感性分析。
- 同频舱：可选 WebXR 头显路线与匿名、同任务多输入方式计时记录。
- 声纹织村：素材许可、AIGC 初稿、人工定稿的过程留痕。
- 星问：HTTPS 来源、主张、局限组成的本机自建知识卡（待人工复核）。
- 镜间：本地 3×3 灰度亮度与 Sobel 边缘密度特征比较，不进行语义识别。

以上新模块均说明模拟/分析边界；正式参赛仍需实际用户测试、来源核验、权利许可和真实设备/数据验证。
