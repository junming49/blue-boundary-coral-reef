## 二、运行环境

- 现代浏览器：Chrome / Edge / Firefox / Safari 近三年版本
- 手机与桌面均可打开，布局自适应 980px / 620px 断点
- 纯静态：无服务器、无数据库、无网络请求、无第三方 CDN
- 少数作品使用麦克风或本地存储，均需用户主动授权，数据不出本机

## 三、技术实现

纯原生 HTML / CSS / JavaScript，单文件页面，无框架、无构建步骤、无包管理器。

- **绘制**：Canvas 2D 程序化绘制（珊瑚礁区、声景曲线、平面图），SVG 由脚本按坐标拼接生成
- **交互**：原生 DOM 事件与自建状态机；键盘全可达，`prefers-reduced-motion` 降级
- **声音**：Web Audio 实时合成雨声、风声、环境底噪，不加载音频文件
- **存储**：`localStorage` 本机保存，提供一键清除；不做上传、不识别身份
- **数据**：导出 JSON / CSV / SVG / PNG，字段自描述，可手工复算

全部图形由代码绘制，**未使用任何第三方图片、字体、图标、地图瓦片或音频素材**。

## 六、数据与边界

七件作品均为可运行的交互作品。以下内容为虚构、模拟或概念设定，页面内已逐项标注，**不作为真实结论或行动建议**：

| 作品 | 边界 |
| --- | --- |
| 01 蓝色边界 | 生态参数为教学假设，不代表真实升温速率或趋势预测；画面为示意性表达，非礁区写实 |
| 02 同频舱 | 楼层、门宽、台阶数、坡道与电梯位置均为示例数据，未开展真实场地测绘；不构成无障碍合规结论 |
| 03 星问 | 星图为示意，不代表真实方位与距离比例；知识条目待天文或科学教育人员专业审阅，不作为考试依据 |
| 04 北斗·归途 | 情节、人物、地名、天气与机构全部虚构；不构成导航、定位或应急救援建议 |
| 05 活字的一夜 | 人物与台词为原创虚构；工序与史料设对照卡，本文非史料复刻 |
| 06 听见校园 | 读数为 0–100 相对强度，不是校准分贝值，不构成噪声达标结论；不上传、不留存音频 |
| 07 一平米静音站 | 概念平面，未做现场测量与使用者访谈；规范只引用原则，不标注条款号，不声称条文级符合性 |

**未开展的验证**（专业审阅、实地测绘、残障用户任务测试、课堂实测、观众传播效果测试）在各作品页「验证与自查」中列为「尚未开展」，不以计划充作成果，也不把未做的事写成做过。

涉及事实的表述，凡未能取得官方逐条原文的细项，页面内标注为「未引用」——即该细项在作品中不予引用、也不据以立论。
