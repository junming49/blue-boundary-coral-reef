# 七作品竞赛原型

本仓库提供七个可直接访问的独立网页原型。入口为 `index.html`：

1. `coral.html` — 蓝色边界：珊瑚修复站
2. `sync.html` — 同频舱：多模态无障碍空间导航
3. `star.html` — 星问：带证据链的天文导览伙伴
4. `beidou.html` — 北斗·归途：一束信号，走出风暴
5. `movable.html` — 活字的一夜：字模学徒的印刷工坊
6. `sound.html` — 听见校园：隐私优先的声景地图
7. `quiet.html` — 一平米静音站：校园微型安静角

## 原型边界

这些页面用于展示交互思路和技术路线。页面中的模拟情境、规则模型与概念尺度均不代表真实科研结论、用户测试或已实施效果。真实数据、专业审核、素材授权、学生团队贡献和 AI 使用记录需由参赛团队据实补充。

珊瑚生态状态、校园楼层地图和安静空间布置均为虚构或概念演示。北斗页面不提供真实救援指导；声景页的相对声强不是校准分贝值。正式参赛前应完成人工核验、真实用户测试和所选赛道的作品重制。

申报简介文本和 Word 初稿作为独立交付文件保存，不包含在本公开仓库中。正式提交前请按学校要求确认赛道、团队信息和材料真实性。
